# OptimizeGPUAndCPU
É um modulo Magisk voltado para Celulares Samsung com OneUI 7 Core Com o Objetivo de Aprimorar o Desempenho do Celular, Compatibilidade com Celulares Samsung com OneUI7Core


A opção 2 que é apenas pro Galaxy A05 ela adiciona uma nova opção no modulo que digitando su no termux e depois rela, vai abrir um menu pra otimizar a GPU do Galaxy A05
E Tbm o Galaxy A05 precisa estar na OneUI7Core e Android 15




Requisitos
Magisk 37.0 Recomendado
Android 15/OneUICore7 Recomendado
Ainda não foi testado na OneUI7 Padrão
